# Screenshot notes

Captured on November 8, 2026 from Little Steps running on an Android 17 / API 37 emulator. Application source matches the MVP merged in pull request #1. These are real screenshots, not UI mockups.

The names, daily totals, and preceding weeks of history are demonstration data created for the documentation. The screenshots do not contain a user's personal activity history. English names and units remain unchanged when switching the interface to Russian, matching the app's behavior.

| File | What it shows |
| --- | --- |
| `today.png` | A daily list with one completed activity and partial measured progress |
| `add-activity.png` | Creating an activity by name alone |
| `quantity.png` | Entering a day's total for a measured activity |
| `calendar.png` | Expanded monthly calendar with completion dots |
| `history.png` | Viewing an earlier day's entries |
| `reorder.png` | Manual reorder mode with drag handles |
| `goals.png` | Advanced goal, unit, and weekday options |
| `reminders.png` | Optional daily reminder and its time |
| `russian.png` | The daily list after switching the interface to Russian |

App behavior, release packaging, and the downloadable APK are unchanged by this documentation update.
